# NOTICE — TafariCraft - Trains

TafariCraft - Trains is an **unofficial derivative and modernization of the original Traincraft mod**.

It is not an official Traincraft release and is not presented as being endorsed by the original Traincraft authors or maintainers.

## Modifications

This project contains substantial changes from the legacy Traincraft codebase, including:

- Porting and compatibility work for Minecraft 1.20.1 and Forge 47.x
- Rewritten entity and rendering systems
- Reworked locomotive movement and traction
- Reworked coupling and multi-car consist behavior
- Reworked steam, boiler, fuel, water, and overheating systems
- Reworked GUIs and HUDs
- Reworked rolling stock behavior
- Reworked track systems
- Bug fixes, stability changes, and new functionality

These modifications should not be interpreted as changes made or endorsed by the original Traincraft team.
